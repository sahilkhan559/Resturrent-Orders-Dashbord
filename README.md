#  Restaurant Sales Dashboard

## Project Overview

This project is an interactive Restaurant Sales Dashboard created using Microsoft Power BI. 
The dashboard provides insights into restaurant sales, orders, products, categories, cities, 
payment methods, order status, and monthly sales trends.

##  Objectives

- Analyze overall restaurant sales performance
- Track total sales and orders
- Identify top-selling products
- Compare sales across categories and cities
- Analyze payment methods
- Monitor order status
- Understand monthly sales trends

## Key KPIs

- **Total Sales:** 2M
- **Total Orders:** 500
- **Total Quantity:** 1.507K
- **Total Items:** 20
